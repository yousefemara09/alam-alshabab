# عالم الشباب — ثيم وردبريس

ثيم مدونة أخبار ومقالات للشباب (دراسة، شغل، تطوير ذات). يدعم العربية RTL، ومجهّز لإعلانات Google AdSense.

## التثبيت
1. اضغط الفولدر `alam-alshabab` كملف zip.
2. وردبريس: المظهر ← قوالب ← أضف جديد ← رفع قالب.
3. فعّل الثيم، وهيتعمل ٦ أقسام تلقائيًا.

## AdSense
المظهر ← تخصيص ← إعلانات جوجل (AdSense).

## المعاينة
المعاينة في فولدر `docs` (GitHub Pages).
